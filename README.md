# Статистика зарплат программистов

Скрипт собирает вакансии программистов в Москве с сайтов Habr Career и SuperJob, рассчитывает среднюю зарплату для популярных языков программирования и выводит статистику в виде таблиц.

## Как установить

Для запуска нужен Python 3.

Скачайте код и создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python3 -m pip install -r requirements.txt
```

## Переменные окружения

Для работы с API SuperJob нужен Secret key.

Зарегистрируйте приложение на сайте SuperJob и получите Secret key.

Создайте в корне проекта файл `.env`:

```text
SUPERJOB_SECRET_KEY=ваш_secret_key
```

`SUPERJOB_SECRET_KEY` используется для авторизации запросов к API SuperJob.

Для Habr Career отдельный ключ не требуется.

Файл `.env` содержит секретные данные и не должен попадать в GitHub.

## Как запустить

Запустите скрипт:

```bash
python3 main.py
```

Пример вывода:

```text
+Habr Moscow-----------+------------------+---------------------+------------------+
| Язык программирования | Вакансий найдено | Вакансий обработано | Средняя зарплата |
+-----------------------+------------------+---------------------+------------------+
| python                | 120              | 45                  | 157500           |
| java                  | 95               | 34                  | 168000           |
+-----------------------+------------------+---------------------+------------------+

+SuperJob Moscow-------+------------------+---------------------+------------------+
| Язык программирования | Вакансий найдено | Вакансий обработано | Средняя зарплата |
+-----------------------+------------------+---------------------+------------------+
| python                | 12               | 7                   | 145000           |
| java                  | 18               | 9                   | 160000           |
+-----------------------+------------------+---------------------+------------------+
```

Числа в таблицах могут отличаться, потому что список вакансий постоянно меняется.
