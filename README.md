# Статистика зарплат программистов

Скрипт собирает вакансии программистов в Москве с сайтов Habr Career и SuperJob, рассчитывает среднюю зарплату для популярных языков программирования и выводит статистику в виде таблиц.

## Как установить

Для запуска нужен Python 3.

Скачайте код и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
